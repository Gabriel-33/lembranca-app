### Lembranca-app

A aplicação lembranca-app, tem o intuito de gerar timilines de eventos(lembranças passadas ou vindouras) e mostrar esses eventos numa galeria ordenada pelo último evento cadastrado.

### Tecnológias usadas
- React js
- Node js
- Mongo DB
- Mongoose
- Multer.

### Instalação
- git clone https://github.com/Gabriel-33/lembranca-app.git
- npm install
- npm install express --save
- npm install cors --save
- npm install multer --save
- npm install mongoose --save
- crie uma base de dados com o nome "lembranca" no mongo DB;
- rode o camando "node ./server.js localhost"
- rode o camando "npm start"
